⚽ API de Resultados en tiempo real

Los resultados se obtienen vía proxy serverless (sin CORS). Para activarlos:
1. Regístrate gratis en football-data.org y copia tu API key.
2. En Vercel → tu proyecto → Settings → Environment Variables.
3. Añade: FD_API_KEY = tu key → Save → Redeploy.
4. Asegúrate de que el repo tiene la carpeta api/football.js subida.
Una vez configurado, grupos y calendario se actualizan automáticamente.
